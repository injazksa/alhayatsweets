## Architecture
- Frontend فقط (React CRA + Tailwind + framer-motion + lenis) — لا حاجة لـ backend/Mongo لأي ميزة مطلوبة.
- الأصول: /frontend/public/assets/{logo,products,campaigns} — WebP متعدد الأحجام (320→1280) + LQIP blur + manifest في src/data/data_images.json.
- SmartImage component: srcset/sizes + reserved aspect ratio (零 CLS) + lazy/eager.
- Code splitting: الأقسام تحت الطية lazy-loaded.
- الشعار: معاد بناؤه كطبقات نظيفة (أحمر #ED1B26 + أبيض + نصوص داكنة) بخلفية شفافة — بدون هالات.
